## Komponen Desain yang Diterapkan

1. **Palet Warna (Color Palette):**
   * Menggunakan warna utama bertema pendidikan modern berbasis ungu tua (*deep violet/indigo*) untuk mencerminkan kesan akademis dan profesional, dipadu dengan latar belakang putih bersih serta abu-abu terang.

2. **Skala Tipografi (Type Scale):**
   * Menggunakan hierarki teks yang jelas mulai dari judul utama (*heading*), sub-judul, hingga teks deskriptif dan label tanggal, guna memudahkan pembaca memindai informasi (*scannability*).

3. **Gaya Tombol & Kartu (Button & Card Style):**
   * **Button Style:** Tombol utama menggunakan sudut membulat (*border-radius*) dengan warna aksen tegas dan efek kontras tinggi saat ditekan.
   * **Card Style:** Desain kartu kursus dan tugas menggunakan bayangan lembut (*drop shadow*) serta pembatas garis tipis untuk memisahkan modul belajar dengan jelas.

4. **Adaptasi Versi Mobile:**
   * Menyediakan tata letak alternatif untuk layar ponsel (*mobile viewport*) yang menyusun ulang elemen dasbor multi-kolom menjadi format satu kolom vertikal yang ramah jempol (*thumb-friendly*).
